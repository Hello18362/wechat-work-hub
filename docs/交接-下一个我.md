## 三、我犯过的错，你别再犯

这一节比上面两节都重要。

**1. 启动脚本被我写坏了。**
我在 `.bat` 里写 `for /f ... do if not defined PYW if exist "%%~dpPpythonw.exe"`，变量名有歧义，脚本在启动前就断了，他双击后网站打不开。
教训：**脚本类和部署类的改动，写完必须自己跑一遍，看到「启动成功」再交付。** 现在已经改成 `.bat` 只负责切目录+找 Python+调 `tools/launch.py`，逻辑全在 Python 里，因为 Python 能测。

**2. 改了后端没重启，让他看到「未知接口」。**
前端是新文件（按 mtime 实时取），后端还是旧进程，`/api/model` 在他那儿是 404。
教训：**动了后端就必须重启并验证接口**，不能跑完单元测试就说好了。现在已加 features 自检，旧进程会提示「请重启」而不是含糊报错。

**3. 推荐了 MIT，但用户要的是「不能商用」。**
MIT 明确允许商用，我当时没问清他的诉求就推荐了，后来他自己提出来才改。现在是 PolyForm Noncommercial 1.0.0。
教训：**涉及授权/法律/合规的选项，先问清他到底想要什么，别按「最流行」推荐。**

**4. 我在沙箱里起的后台进程会被回收。**
我试过 `Popen` + `DETACHED_PROCESS`，日志显示「控制台已就绪」，命令一结束进程就没了。
教训：**不要承诺「我帮你把服务起起来」，持久服务只能他自己双击 `一键启动.bat`。** 我能做的是把脚本写对，让他一次成功。
