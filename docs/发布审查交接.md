## 二、这个项目是什么

本地优先的微信群聊整理工具：从本机微信数据库读取指定群的消息 → 语音转写 / 图片描述 / 公众号正文 → 用大模型总结成任务清单 → 输出 Markdown + HTML 报告。

关键事实（审查时会用到）：

- 数据源是**外部工具**解密出的 SQLite，解密工具本身不在仓库里；
- 三种总结模式：`file_output`（离线，生成待处理文件）/ `deepseek` / `openai` 兼容（在线）；
- 本地控制台是标准库 `http.server`，只监听 `127.0.0.1:5710`，零 Web 框架。

### 4. 修掉的两个「别人用不了」的 bug

- `一键启动.bat`：原来写死 `D:\我的空间\...` 和 `C:\Users\0\...\pythonw.exe`。现在 `.bat` 只做三件事（切目录、找 Python、调 `tools/launch.py`），全部启动逻辑放进 Python：
  - `tools/launch.py`：清理旧进程（只杀 Python 进程）→ 后台拉起服务 → 轮询端口 → 打开浏览器。
  - 之所以不把逻辑写在 `.bat` 里：批处理的 `for /f` + `if defined` 组合在不同机器上极易出歧义（第一版就踩了），而 Python 版可以本地跑测试。
  - `.bat` 必须保持 **GBK 编码 + CRLF + `chcp 936`**，并设置 `PYTHONIOENCODING=gbk:replace`，否则窗口里中文乱码。
- `刷新数据.bat`：原来写死解密工具路径，改为调用 `tools/refresh_data.py`
