# 演示站（沙盘版）

「微信群聊 → AI 工作简报 → 桌面待办卡片」整套流程的**可点击演示**。
纯静态，不需要 Python、不需要微信、不需要联网。

## 要发微信 / 用手机看 → 用单文件版

用微信发 `index.html` 是**发不出去的**（微信只发单个文件，CSS/JS 全丢），
对方点开就是没有样式的白页、状态永远卡在「正在检测服务…」。

改成这种写法就行：

```bash
python tools/build_singlefile.py
```

产物 `demo-site/dist/WeChatWorkHub-演示-单文件.html`（约 250 KB），
CSS、JS、三份示例报告**全部内联**，微信发送 / 邮件附件 / U 盘拷贝，
双击或点开就能用，手机上另有小屏适配（导航收窄、表单单列、卡片全宽）。

Windows 也可以直接双击 `demo-site/打包单文件.bat`。

> 单文件版里没有「桌面悬浮窗」那个入口——它是独立页面 `widget.html`，
> 演示悬浮窗还是要用电脑打开多文件版。

## 打开方式（电脑上完整版）

**Mac / Windows：直接双击 `index.html`。**

已在 `2026-11-18` 修掉两处让 `file://` 跑不起来的问题：

1. `mock-api.js` 里 `new URL(url, location.origin)` —— `file://` 下 origin 是 `"file://"`，
   解析结果正确；之前的失败是因为截图/加载时序，不是这段逻辑。
2. `app.js` 里 3 处 `window.open('/reports/...')` 用的是**绝对路径**，
   `file://` 下会解析到磁盘根目录而 404。已全部改成相对路径 `reports/...`。

如果 Safari 因为本地文件策略仍然不加载，退一步用本地服务（不需要装任何东西，Mac 自带）：

```bash
cd demo-site
python3 -m http.server 5730
# 然后浏览器打开 http://127.0.0.1:5730/
```

Windows 上也可以双击 `预览.bat`（需要装 Python），效果相同。

## 演示顺序（建议照着走）

| 步骤 | 在哪 | 看什么 |
| --- | --- | --- |
| ① | 控制台首页 | 群列表、置顶、按群浏览、状态「chatlog 已连接」 |
| ② | 点「生成工作报告」 | 进度条分阶段推进，完成后列表顶部多一份报告 |
| ③ | 点报告卡片「查看 HTML 报告」 | 完整简报：消息统计、任务安排、领导决策、聊天记录 |
| ④ | 右上角「桌面悬浮窗」 | 玻璃卡片列表、滚轮滚动、点圆圈标完成（卡片飞进右上角）、收起成球 |

第 ④ 步是这次新加的：`widget.html`。

## 页面结构

```
index.html      控制台（群管理 / 生成报告 / 历史报告）
widget.html     桌面悬浮窗演示（玻璃卡片、完成动画、收起成球）
reports/        三份示例报告，由项目自己的渲染器生成，外观与真实一致
app.js          控制台前端逻辑（与真实版相同）
mock-api.js     假后端：拦截 /api/*，返回示例数据
style.css       控制台样式
demo.css        演示提示条 + 导航入口样式
预览.bat        Windows 本地起静态服务
```

## 数据说明

- **控制台部分**（`index.html`、`reports/`）用 `mock-api.js` 里的**编造的示例数据**，
  群名统一带「示例 ·」前缀，不含任何真实聊天内容。
- **悬浮窗部分**（`widget.html`）同理，10 张卡片全部是**编的示例任务**（群名统一
  「示例 · 」，人名用张经理/李工/辅导员这类通用称呼）。2026-11-20 已把早先带入的
  真实群名与同学昵称全部替换掉，仓库里不含任何真实聊天内容。

演示时建议主动说明这一点：「界面是同一套，控制台和悬浮窗都用示例数据，真跑的时候
卡片是由当天微信群消息自动抽出来的」。

## 快捷键（在 widget.html 里）

| 键 | 作用 |
| --- | --- |
| `1` `2` `3` | 切换背景：日落 / 深色 / 白色网页（用来说明玻璃在任何背景下都成立） |
| `H` | 隐藏左下角操作提示 |
| 滚轮 | 滚动卡片列表 |

URL 参数可以直接跳到某个画面，方便截图：

```
widget.html?done=2      预置两条已完成（右上角出现两张迷你卡）
widget.html?ball=1      直接收成玻璃球
widget.html?bg=paper    指定背景
```
